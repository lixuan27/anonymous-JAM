# JAM

This anonymous repository contains the code release and the interactive review demo for JAM.

## Interactive demo

[Open the JAM demo](https://anonymous.4open.science/api/repo/anonymous-JAM-B9BF/file/demo/index.html)

The demo presents the method, benchmark results, controlled analyses, and robot rollouts in a self contained static page. All media are stored inside `demo/`, and the page does not load analytics, cookies, or external resources.

## Code

The implementation, training recipes, evaluation tools, and configuration files are organized in this repository. The demo is kept in `demo/` so that code and qualitative evidence remain accessible from the same anonymous review entry.
